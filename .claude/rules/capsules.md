# Capsules (Pokémon seulement ; absentes de la version Play Store, voir `appli-mobile.md`)
- `supabase-v3.sql` : tables `dex_species` (rareté des 1025 Pokémon), `capsule_state`, `caught` en lecture seule ; `capsule_status`, `capsule_open` (tirage), `capsule_dex`.
- `js/pokedex.js` (`App.pokedex` : noms FR, rareté identique au SQL, visuels PokéAPI `official-artwork`, `img(id)` force un nombre, `family(id)` = évolutions par stades, `EVO`/`EVO_FAR` tirées de PokéAPI ; `speciesModal(id, dex)` montre évolutions + chromatique, grisés « ? » s'ils manquent ; toucher le Pokémon révélé ouvre la capsule suivante ; « Attrapés seulement » visible seulement dans une région).
- `js/capsules.js` (`App.capsules`), `js/views/capsules.js` (`#/capsules`, animation d'ouverture, `pickAvatar`, `setAvatar`). Avatar = `profile.avatarPoke = {id, shiny}` (l'ancienne photo `profile.avatar` reste lue). La capsule est un dessin original (pas de Poké Ball), `capsuleSVG(cls, size, gold)`. Classes d'animation préfixées `co-` (`.reveal` existe déjà).
- **Boutique (`supabase-v5.sql`)** : monnaie **éclats** à l'écran (colonne `coins`) ; `bonus` (capsules achetées, hors limite de 10), `big` ; `capsule_price(tier, shiny)` = 1/3/8/20/100/150 ×5 si chromatique ; `capsule_open(p_kind default 'normal')` (`'grande'` : rare 45 %, très rare 33 %, légendaire 17 %, fabuleux 5 %, chromatique 3 %) ; `capsule_sell`, `capsule_sell_dupes()` (garde 1 normal par espèce, chromatiques jamais vendus), `capsule_buy('capsule'|'grande', n)` (20 / 150 éclats) ; `capsule_log`. Revente moyenne : capsule ≈ 7, grande ≈ 38 (pas de boucle infinie).
- Site : `App.capsules.sell/sellDupes/buy/price/dupes/total`, `state.shop` faux si v5 absent (« il reste une étape »). `.shop-item.can` (dorée pour la grande) seulement si assez d'éclats. Impossible de vendre le dernier exemplaire de son avatar ; confirmation pour le dernier exemplaire, légendaires/fabuleux et chromatiques.
- **Rareté cachée « Dieu » (Arceus seul)** : `App.pokedex.TIER[7]` (`secret: true`), `tier(493) = 7` côté site seulement ; le serveur le tire et le vend comme un fabuleux (tier 6, `PRICES[7] = 150`), aucun SQL. Jamais nommée tant qu'on ne l'a pas : `tierPill(t, known)` → « ??? », filtre « ??? » (valeur 7), absente des chances affichées. Ouverture : `App.capsuleGod` (`js/views/capsules-god.js`, `css/13-arceus.css`, son `App.sfx.god()` / `godTitle()`), ~10 s **impossible à passer** (`locked` dans `openAnimation`). Rejouer pour tester : remplacer `App.capsules.open` par une promesse qui renvoie `{ species: 493, tier: 6, count: 1, stock: 2 }` puis `App.views.capsules.openLoop()`.
- **18 formes d'Arceus (v3.72, `supabase-v22.sql`)** : colonne `caught.form` (Arceus seul), `arceus_forms()`, `capsule_open` choisit une forme **pas encore possédée** (sinon au hasard) et renvoie `form` + `form_count` ; `capsule_forms()` = mes formes ; `capsule_sell` vend d'abord les doubles d'une même forme, `capsule_sell_dupes` garde une par forme. Site : `App.pokedex.FORMS/FORM/form(id, f)` (forme validée, jamais une valeur inconnue), `img(id, shiny, form)` (`493-fire.png`, existe aussi en `shiny/`), `fullName`, `avatarImg(a)` ; `avatarPoke.form` (filtré dans `friends.js`) ; `App.capsules.forms()` (vide sans v22) ; fiche = grille « Les 18 formes », case du Pokédex « x/18 », ouverture « Forme Feu », « Nouvelle forme ! », couleur du type (`--gt`). Démo PC : `#/capsules?arceus=feu-shiny`.
- **Apparitions spéciales (v3.73)** : `App.capsuleFx.get(id)` (`js/views/capsules-fx.js`, styles à la fin de `css/13-arceus.css`) joue par-dessus l'ouverture normale, après `co-reveal` (classe `fx.cls` posée juste avant) ; rien ne change au tirage ; passable comme une ouverture normale (les effets se jouent quand même à la révélation). Carapuce (7) : tourbillon d'eau, lunettes de soleil (SVG original, placées sur `official-artwork/7.png` : `left 19 %, top 13,5 %, width 37 %`, −7°), son `App.sfx.shades()`, bannière « Carapute », petite danse (`fx-dance`, toute la case `.cap-mon` bouge). Démo PC : `#/capsules?capsule=7` (ou `7-shiny`). Recherche du Pokédex des capsules : `#cp-q` (nom ou numéro, dans tout le Pokédex, ignore région et « attrapés seulement »).
- **Formes génériques (v3.75, `supabase-v23.sql`)** : `pokemon_forms(sp)` (493 → `arceus_forms()`, 201 → 28 formes Zarbi `a`…`z`, `exclamation`, `question`) ; `capsule_open` donne une forme pas encore possédée à tout Pokémon qui en a ; les Zarbi déjà attrapés ont reçu une lettre différente chacun (au hasard). Site : `App.pokedex.formsOf(id)` / `formInfo(id, f)` / `form(id, f)` (la 1re forme = image sans suffixe : `201.png` = A, `493.png` = Normal) ; `App.capsules.forms(species)` (cache Map espèce → Map forme) ; fiche « Les N formes », case « x/N », ouverture « Lettre B » / « Signe ! » / « Forme Feu ». Nouveau Pokémon à formes : l'ajouter dans `FORMS_OF` (pokedex.js), `pokemon_forms()` (SQL) et la liste `[P().GOD, 201]` de `refreshDex`. Démo PC : `#/capsules?capsule=201-b`.
- **Grands légendaires (v3.76)** : `App.capsuleLegend` (`js/views/capsules-legend.js`, `css/14-legendaires.css`, sons `App.sfx.legend(key)`) remplace les secousses par une scène de ~4,5 s (`back` derrière la capsule, `front` devant, `steps` = classes posées sur `.cap-ov`, « q » = tremblement), puis `burst()` (éclatement normal). **Les classes d'étape ne doivent jamais porter le nom d'un élément du décor** (bug vu : `.lg-dragon` rétrécissait tout l'écran). Impossible à passer la 1re fois (`App.capsuleFx.seen`), passable ensuite. Les 12 : Groudon 383, Kyogre 382, Rayquaza 384 (~7 s, furieux : orage noir, yeux qui s'ouvrent dans les nuages et regardent autour, clignent puis se plissent, nuages qui roulent, éclairs répétés « t », écran rouge, sphère d'énergie qui aspire, rayon qui pulvérise la capsule, titre « Seigneur des cieux »), Mewtwo 150 (~5,5 s : cuve, verre figé, « Créé par l’homme »), Mew 151 (cascade dans la forêt, arbres ronds, bulle rose qui sort du bassin et fait un looping, cœurs, cri « Meeew » synthétisé par `voice()` dans sfx.js), Giratina 487 (Monde Distorsion), Lugia 249 (~5 s : tempête sur l'océan, lueur des profondeurs, la mer se soulève, grandes ailes en V, la tempête s'en va, « Gardien des mers »), Ho-Oh 250 (aube, arc-en-ciel en bande floue, plume, Feu Sacré en flammes multicolores, ailes de feu ; « Gardien des arcs-en-ciel »), Celebi 251 (horloge, sépia), Deoxys 386 (boule de feu à traînée en cône qui grossit, explosion et fumée, hélice d'ADN en points), Shaymin 492 (Gracidées), Léviator rouge 130 (`shinyOnly`, lac Colère). Briques communes : `sky()`, `parts()`, `stars()`, `shocks()`, étapes « q » / « f » (couleur `--lgf`) / « r » (`--lgr`, aussi couleur des rayons à la révélation), `title`, `vars`. Hiérarchie voulue par Arnaud : Arceus > légendaires (vraies scènes) > Carapute (simple clin d'œil). **Arnaud n'aime pas les effets en traits fins** (rayures, rubans, barres) : préférer formes pleines, lueurs floues, nuages, particules.
- **Souvenirs** : `App.settings.fxSeen` (clés « 7 », « 383 », « 130s » = Léviator chromatique ; suit le compte) ; `App.capsuleFx.souvenirs()` (appelée 4 s après le 1er `capsule_status` réussi, une fois par lancement) **impose** un écran plein `.fx-call` « Nouvelle(s) apparition(s) ! » (silhouettes dorées, aucune annulation : n'importe quel toucher lance, ce qui autorise aussi le son) pour les Pokémon possédés pas encore vus, puis `App.views.capsules.replay(id, shiny)` (faux tirage, pastille « Souvenir », marque vu). Avant (v3.76) : une fenêtre `ask` trop discrète, annulée en touchant à côté.
- **Capsule de la semaine (v3.79, `supabase-v24.sql`)** : change **chaque jeudi à 20 h (Paris)** (`capsule_week_start`). Événements (75 éclats, 20 % de costume) = semaine contenant le 31 oct. (Halloween), le 18 et le 25 déc. (Noël, Pikachu **ou** Cadoizo), le 1er janv., le 14 févr., Pâques (`easter_day`), le 17 mars (Saint-Patrick), le 14 juillet (Été) ; sinon 50 éclats, rotation de 27 semaines types/régions (`capsule_week_theme`, ancre 1er janv. 2026 20 h). `capsule_open('week')` : rareté pondérée parmi celles du thème, chromatique 2 %, jamais Arceus ; `_capsule_json.week = { theme, price, ends }` (le site n'affiche l'article que si présent). Costumes = formes de Pikachu (25 : `halloween`, `xmas`, `newyear`, `valentine`, `patrick`, `easter`, `summer`) et Cadoizo (225 : `xmas`), `skin: true` dans `FORMS_OF` ; images **dessinées pour le site** `img/skins/[shiny/]25-<clé>.webp` (accessoire SVG posé sur l'image officielle dans un canevas, exporté en webp) ; jamais donnés par une capsule ordinaire (`pokemon_forms` ne les connaît pas) ; **ne se vendent pas** (`capsule_is_skin`, exclus de `capsule_sell` et `capsule_sell_dupes`). Site : `js/capsule-themes.js` (`App.capsuleThemes.THEMES` : mêmes listes que le SQL, `current()` d'après `state.week`, `until()`), article `.shop-item.theme` (+ `.event`) **placé avant la grande capsule, texte court (`short` + « jusqu’à jeudi 20 h »), petit bouton « i » discret (`.info-btn`) → fenêtre des Pokémon possibles (costumes d’abord)**, ouverture légèrement différente (`co-week` : fond teinté `--wk2`, symboles du thème `.wk-ic` qui s’envolent à l’éclatement), ouverture « Costume Halloween ! », fiche « Les costumes ».
