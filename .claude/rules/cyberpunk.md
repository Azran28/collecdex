# Cyberpunk TCG (v3.96, `js/games/cyberpunk.js`, 10ᵉ licence, WeirdCo sous licence CD PROJEKT RED)
Même logique que Wankul (visuels gardés dans le site) et Star Wars (prix TCGplayer) ; voir `wankul.md`, `starwars.md`. Id de licence `cyberpunk`, préfixe `cp`. Arnaud a reçu ses cartes le 31 oct. 2026 ; **pas encore de photo** (promises pour le lendemain) : tout a été mesuré sur les visuels officiels en grand (733 × 1024).

## Données
- **Base officielle** (cyberpunktcg.com/cards, servie par Netdeck.gg) : `GET https://api.netdeck.gg/api/cards/cyberpunk?offset=N&limit=100&language=fr|en` (**`offset`, pas `page`** : `page` renvoie toujours les mêmes 100 ; `limit` plafonné à 100 ; CORS accordé). Une fiche par carte (151 en anglais, 150 en français en oct. 2026) avec `printings` = toutes ses impressions (860), anglaises et françaises : `set.code` (« welcometonightcityretail », « …-fr », « …-FR », « embracingpowerretailstarterde-fr » tronqué), `collector_number` (« 005a », Bêta « β005a »), `rarity`, `artist`, `language`, `localized_name` (« V — Gosse Des Rues »). Fiche `fr` : `name`, `subname`, `rules_text` en français ; `card_type` (Legend Unit Gear Program), `color` (Red Blue Green Yellow), `cost`, `power`, `ram`, `is_eddiable`, `classifications` (tags).
- **Visuels** : `image_url` = adresse CloudFront **signée, valable 5 minutes** (`Expires=`), refusée sans signature (403, relais compris) → `outils/ci/cyberpunk-cartes.mjs` télécharge chaque visuel aussitôt et en garde une **copie 300 px webp q0,8 dans `data/cp-img/<id>.webp`** (589, 15 Mo, comme Wankul ; `sources.json` = chemin d'origine : refaite seulement si le visuel change ; conversion par Chromium/Playwright sur le robot, dans le navigateur intégré sur le PC). Visuel **français d'abord**, anglais sinon (Bêta, tournois, promos).
- `outils/ci/cyberpunk-cartes.mjs` → `data/cp-cartes.json` (300 Ko, dans le dépôt), chaque lundi par `index.yml` (étape « Liste des cartes Cyberpunk », `cartes_cp`, ajoute aussi `data/cp-img/`). Cache `cp1:index`. Format : `id, s, l, n / st (nom / sous-titre FR), ne / se (anglais), t (l u g p), c (r b g y), co, p (Power), ram, ed (revendable €$), tg (tags), x (texte FR avec {Call}…), r, a, u (chemin du visuel), lg (fr / en), cid (fiche Netdeck : même carte dans toutes les séries), ln, tp (produit TCGplayer)`.
- **Une carte = une impression dans une série** (anglaise ou française = même carte). Séries (`SETS` de l'outil) : `wnc` Welcome to Night City (« MS01 - WNC », 172 : 001–140 + 005a/005b, iconiques 141–171 = `MAX` 140 → « 141 numérotées + 31 versions iconiques »), decks `hei` (SD01 - HEI), `emb` (SD02 - EBP), démos `dar` / `dme` (PRM - DD2 / DD1), promos `bt` (cartes bonus des displays, PRM - WNC), `prr` (avant-première, PRR02 - WNC), `prm1` (PRM01), `ncb1` / `ncs1` / `eor1` (tournois NCB01 / NCS01 / EOR01 - WNC), `jdg` (JDG - WNC) ; **Bêta du Kickstarter** (groupe à part `cp-beta`, anglais seulement, numéros imprimés « B010 ») : `wncb`, `heib`, `embb`, `btb`, `prrb` (PRR01 - WNC). Série inconnue → id tiré du code de la base (à ajouter à `SETS`).
- **Id = série + numéro** : `wnc-010`, `wnc-005a`, `wncb-010`. Numéro toujours sur 3 chiffres (une fiche anglaise donnait « 10 »).
- Raretés : C Commune, U Peu commune, R Rare, E Épique, NR Nova Rare (promos), S Secrète, IL Légende iconique, IC Iconique, IS Secrète iconique. **Une seule version par carte** (TCGplayer : communes et peu communes normales, Rare et au-dessus brillantes) → pas de mesure du brillant.
- **Prix** : `outils/ci/prix-cyberpunk.mjs` (TCGplayer catégorie **92**, via tcgcsv) → `_site/data/cp-prix.json` (`.gitignore`) ; relié par `tp` (groupe TCGplayer nommé dans `SETS`, numéro « B005a » → « 005a », début du nom anglais). Un seul produit par carte : son prix va à la version de la carte. Sans prix chez TCGplayer (oct. 2026) : iconiques de la boutique, avant-première boutique, Night City Showdown, démos, arbitres. Cardmarket : bloqué par Cloudflare (pas vérifié) → liens vers TCGplayer (`refLink`, `boosterLabel`).
- **Visuel de série** : produit TCGplayer `pk` (« … Booster Pack », « Starter Deck: … »), image entière (pas de `PACKS_CROP` mesuré) ; promos : `logoText` = code imprimé.

## Reconnaissance (mesurée sur les visuels officiels seulement)
- **Code imprimé à la VERTICALE le long du bord gauche, en bas** (« MS01 - WNC [A] », se lit en tournant la carte d'un quart de tour vers la GAUCHE : `leftTurned`, bandes `CODE_BANDS` 0,935…0,99 × 0,75…0,99) ; **numéro en biais** dans l'onglet jaune du coin bas-gauche (« 010 », « B010 ») : coin `NUM_BOX` tourné de −50° (`numCorner`, −45…−60 lisent, ±30 non). PaddleOCR lit « MS01 - WNC [A] », « SDO1 - HEI TAI », « NCBO1-WNC », « BO10 ». `codesIn` exige le code de la série ET un numéro de 3 chiffres (rien sur « 025/165 ») ; code complet → 1, préfixe seul (« PRM ») → 0,6 ; « B » devant le numéro → la Bêta, sinon la boutique (×0,3 pour l'autre).
- Nom lu en haut (Légendes : nom + sous-titre) ou au-dessus du texte (`NAME_BANDS`) ; noms français ET anglais dans `names()` (cartes Bêta anglaises).
- 6 visuels officiels en grand : **6/6 justes et sûrs**, 0,5–1,4 s (code + nom).
- Vérification par l'image : `data/cp-index` (589 cartes, `CP_INDEX_V = 1`, 1,4 Mo) construit depuis `data/cp-img` (`labo-index-op.js`, `FILE.cyberpunk`). Même illustration en boutique et en Bêta (anglais / français) : `twinsOf` = même `cid` et même numéro ; sans numéro lu, la boutique devant, « à vérifier » (`twinDoubt`).
- `detectGame` / `textScores` : code, CD PROJEKT, WEIRDCO, ILLUST., Go Solo, Gigs, Night City, GEAR / PROGRAM, « Unité alliée / rivale », « +2 Power à une Unité », €$ / Eddies ; `recognizer-text › OTHER` : CD PROJEKT, WeirdCo, Go Solo, Night City, codes. Sur les visuels : Jônin et Lames Mantis reconnus « Cyberpunk », Adam Smasher, Viktor Vektor (deck), Bombus (tournoi) non (trop peu de texte lu) → la vérification par l'image prend le relais.
- **À faire avec les photos d'Arnaud** : cadrage (bords noirs), zones du code / numéro, classeur, dos (certification : pas fait, `backScoreOf` retombe sur le modèle Pokémon), « Toutes » et mode Pokémon.
