# Wankul (v3.48, `js/games/wankul.js`, 7ᵉ licence, Wankil Studio : Laink et Terracid)
Même logique que Final Fantasy (voir `finalfantasy.md`) ; ici seulement ce qui diffère. Arnaud a des cartes (photos `_tests-scanner/wankul/`, 20 oct. : 1 = dos en main, 2 = dos en pochette brillante (page), 3 = Tanguy Gagnant du Ticket d'or #F en main, 4 = Dénué d'éclat L-ARGENT #178 brillante en main, 5 = page 3 × 3 Stellar : 6 terrains couchés T#20…27 + 3 dos, 6 = page Stellar UC#109…117 + 1 dos, 7 = Chef kebab C#55 en pochette, 8 = gros plan de 4 cartes (Pompiste, Boulanger, 2 Tarot) + bords d'autres).

## Données
- **Wankuldex officiel** (wankul.fr, boutique Shopify) : `GET https://wankul.fr/apps/wankul/api/wankuldex/cards?page=1&limit=100&sort=default&dir=asc` (liste : id, nom, numéro, effigie, rareté, série, artiste, images ; 958 cartes en oct. 2026) + `…/cards/<id>` (détail : `force`, `cost`, `rules`, `combo`, `quote`, terrains `effectWin` / `effectLose` / `effectSpecial`, `variants` = autres numéros du même personnage, pas des versions). **Pas de CORS** ; trop d'appels d'un coup → 429 (attendre, l'outil réessaie). Lien d'une carte : `https://wankul.fr/apps/wankul/wankuldex?card=<id>` (`refLink`).
- **Images** : `/apps/wankul/api/media/<chemin>_main.{jpg,png}` (430 × 600, carte entière à coins carrés) **refusées hors du site** (« Hotlinking not allowed », 403, relais images.weserv.nl compris) ; données seulement à une demande `Sec-Fetch-Site: same-origin` → redirection vers une adresse OVH signée valable 90 s. → `outils/ci/wankul-cartes.mjs` télécharge chaque visuel et en garde une **copie 300 px webp q0,8 (~22 Ko, 21 Mo en tout) dans `data/wk-img/<id>.webp`** (dans le dépôt ; `sources.json` = chemin d'origine de chaque copie : refaite seulement si le visuel change). Conversion par Chromium (Playwright, installé par le robot) ; sur le PC (pas de Playwright) : téléchargement par un petit script + conversion dans le navigateur intégré (serveur de travail avec `POST /__save`). `img.card` rend l'adresse complète (`new URL(…, document.baseURI)`) : la vérification par l'image lit les visuels depuis un worker. `_ur.png` / `_leg.png` / `holoMasks` = calques d'effet brillant du site (pas des visuels).
- `outils/ci/wankul-cartes.mjs` → `data/wk-cartes.json` (390 Ko), chaque lundi par `index.yml` (étape « Liste des cartes Wankul », `cartes_wk`, ajoute aussi `data/wk-img/`). Détails déjà connus et visuel inchangé = repris du fichier (peu d'appels ; `WK_REFRESH=1` pour tout relire). Cache `wk1:index`. Format : `id, s, l (numéro imprimé), n (nom, capitales de l'API → « Chef kebab »), r (rareté), ra (sigle API), e (effigie l tc g ra d t to), pe (édition), f (force), co (coût), x (texte), cb (COMBO), q (citation), w / lo / sp (terrain : gagnant / perdant / spécial), a (artiste), h (brillante), u (chemin du visuel), wid (id API)`.
- **Id = série + numéro** : saisons `or` (Origins, S1), `ca` (Campus), `ba` (Battle), `st` (Stellar), `le` (Legacy, numéros « 001 » → `le-1`, DUO `le-179a`) ; hors-série en 5 séries : `to` (Gagnants du Ticket d'or, `to-4f` = saison 4 lettre F), `eg` (Éditions Gold), `pgw` (`pgw-23-1`), `sp` (Starter Packs, `sp-st-s181`), `ed` (Éditions spéciales, `ed-alpha`, `ed-noel23-27`). Groupes `wk-main` / `wk-hs`. `numLabel` : pas de total affiché (« n° 55 », comme la carte « C#55 »).
- Raretés : T Terrain, C, UC, R, UR1, UR2 (holo), DUO, L-B / L-A / L-O (légendaires), T-OR, Gold, PGW, SP, ÉD. **Une seule version par carte** (UR, légendaires… = autres numéros, déjà brillantes) : `variants` = `{ holo }` si brillante (`h`), sinon `{ normal }` → pas de mesure du brillant.
- **Prix : aucun** (ni Cardmarket ni TCGplayer ; seulement des annonces) → `noPrices` : la page d'une série ne charge pas de prix et ne montre pas de coût, la fiche dit `priceNote` et le lien mène au Wankuldex (`refLink`, `card.js`).
- **Visuel de série** : booster de chaque saison sur la boutique (`cdn.shopify.com`, CORS `*` ; CSP `img-src` + `connect-src`), `PACKS` = fichier + zone du sachet mesurée à 300 px (Battle : pas de booster seul, l'éventail de 8 boosters) ; hors-série : `logoText`.

## Reconnaissance
- Code **en bas à droite**, après la saison et l'effigie : « STELLAR · LAINK · C#55 », « STELLAR · TERRACID · L-ARGENT #178 », « ORIGINS · LAINK · L#179 », Ticket d'or « STELLAR · GAGNANT TICKET D'OR #F », **terrains couchés** « STELLAR T#20 » (vertical sur la carte debout). `codesIn` : rien sans `#` (ni `*` / `£` mal lus) ; saison lue (tolérante, `seasonIn`) → poids 1, sinon toutes les saisons à 0,4 (l'image tranche) ; rareté lue qui ne correspond pas à la carte du numéro → ×0,4. Bandes PaddleOCR `OCR_BANDS` (0,925…0,985 × 0,45…0,97) + nom (`NAME_BANDS` 0,64…0,77) ; **terrain** : photo tournée d'un quart de tour (`turned`) puis `T_BANDS`, seulement si rien n'est lu debout (ou si l'image dit « terrain »).
- Vérification par l'image : `data/wk-index` (958 cartes, `WK_INDEX_V = 1`, 1,5 Mo) construit depuis `data/wk-img` (`labo-index-op.js`, `FILE.wankul`). Pas de jumelles (même personnage = autres illustrations).
- `detectGame` / `textScores` : code ≥ 0,9, wankul, Laink, Terracid, saison + « # », COMBO, « Le gagnant / Le perdant », Scorez / meule, « Art : » ; `recognizer-text › OTHER` : laink, terracid, le gagnant / perdant, scorez, meule, saison + « # », « ticket d'or » (Tanguy en mode Pokémon passait pour Hypotrempe).
- **Dos / certification** (`recognizer-image › wkBackScore`) : carte bleue tachetée, logo blanc au milieu → presque rien de chaud (`warm` ≤ 0,15), du bleu (`blue` ≥ 0,35), détail concentré dans la bande du logo (`ratio` ≥ 3, `band` ≥ 35), fenêtre décalée jusqu'à ±12 % en hauteur (case de classeur de travers, page 6 : logo à 0,7). Dos des photos 0,62–0,87 ; 958 visuels officiels ≤ 0,18. En classeur, dos sûr comme Pokémon et Final Fantasy. `certify.js › backOf` l'inclut. Test `tests/dos-wankul.jpg`.

## Ailleurs

- Combats : `battle.fighterWK` (Personnages ; PV = 40 + force × 15, attaque = 10 + force × 8, coût = coût de la carte 1–3, COMBO = 2ᵉ attaque +20), `WK_EFF` (effigie → type : Laink → fire, Terracid → water, Invité → psychic, Random → colorless, Ticket d'or → lightning), `LEVELS_WK` (Viewer → Wankil, Personnages d'Origins), `battleCards.effectOfWK` (**les Terrains** = cartes du deck Avancé : « +1 en Force » → Stade, personnage gratuit / moins cher → +1 énergie, plus cher → énergie adverse en moins, défausser un personnage → Rafale, reprendre un personnage → Réanimation, piocher → +1 énergie, le perdant défausse sa main → protection, le perdant meule N → +N × 10) ; `isWkCard` = `kind 't'` + champ `effigy` (les terrains d'Origins ont l'effigie « Random ») ; énergie = **Gemme** dessinée (`gemCard()`, `GEM`, `img/combat/gemme-wankul.svg`), +3 par `withDon` ; `AI_BAGS_WK`, deck de prêt (2 Valheim, Moria, Fnaf, Agrou, 3 Gemmes) ; `LIC.wankul` (Deck, « plateau du Wankil Studio »), `say` (personnage, gemme), `WK_NAMES` ; décor `img/combat/studio-wankul.svg`, dos `dos-wankul.svg`, CSS `.g-wankul` (encadrés blanc cassé à bord noir comme les cartes, gemmes dorées).
- Badges : `wk-duo`, `wk-terrains`, `wk-ticket`, `wk-legende`. Icône `wankil` (deux têtes). `friends.js` / `duel.js` acceptent `data/wk-img/<id>.webp` et la gemme ; `battleCards.offImg` rend le visuel du site. `sw.js` : `data/wk-img/` dans le cache des images (1 500 max), boosters `cdn.shopify.com` aussi.
- Tests : `tests/unit.js` (données, visuel lisible, codes, dos, combattant + terrains, « Toutes » + mode Pokémon, import, index), `tests/pages.js`, `tests/combat.js`.
