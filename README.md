# CollecDex

Le « Pokédex » de ta collection de cartes : séries, progression, raretés, prix, vitrine, et ajout de cartes par scan.

- Site : https://azran28.github.io/collecdex/
- Données cartes et prix : [TCGdex](https://tcgdex.dev)
- Comptes et synchronisation : Supabase
